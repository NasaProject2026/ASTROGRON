**الحكم:** `PARTIAL_VERIFIED_REPAIR / FULL_RUNTIME_RETEST_REQUIRED`.

هذا التقرير مراجعة جديدة للحزمة المرفقة، وليست إعادة صياغة لتقرير نجاح V4 الموجود أصلًا. جرى فحص الشيفرة المصدرية، الـUML/contract models، ملفات واجهة المستخدم، إعدادات Next/MapLibre، لقطات Chromium المرفقة، سجلات الاختبارات، أصول الصور، بيانات التراخيص، مسار سلامة ZIP، وبنية التصريحات العلمية. **لم يُتح إعادة تشغيل بناء Next.js أو Playwright داخل هذه البيئة** بسبب عدم إمكانية تنزيل حزم npm (EAI_AGAIN / ENOTCACHED)، وتعذّر إنتاج لقطة متصفح Chromium محلية حتى لصفحة HTML اختبارية بسيطة. وبالتالي تُذكر الاختبارات الأصلية 47/47 و5/5 كـ **أدلة أرشيفية ضمن ZIP الأصلي** وليست نتائج مستقلة معادة بعد هذه التغييرات.

## 2. مراجعة الاستقلال العلمي — ما حافظنا عليه

- `SYNTHETIC_UI_DEMO` يعرض بيانات سيناريوهات أوبسالا المصنّعة للواجهة فقط، وليس نتيجة علمية محققة أو نصيحة زراعية ميدانية. يبقى `FIELD_RECOMMENDATION_ELIGIBILITY: BLOCKED`.
- `RECORDED_M14_RESEARCH` و`REAL_SCIENTIFIC_BACKEND` لا يمكن اعتبارهما متصلين دون مصدر M14 والربط الخلفي؛ لا تُنسخ بيانات Uppsala تلقائيًا إلى Kenya/Australia/custom sites.
- NASA GIBS Blue Marble وEOX historical raster يعززان **العرض الجغرافي**، لكن ذلك ليس دليلًا على استيراد NASA POWER/GPM/SMAP/HLS علميًا في محرك التوصية. يجب أن يستمر هذا الفصل حتى إجراء دراسة المصدر/التاريخ/الدقة/المحاذاة المكانية والأثر على المخطط.
- وجود `BACKEND_NOT_CONNECTED` في الحزمة حد معماري **مقصود**؛ لا يجوز التحايل عليه عبر إدخال نتائج fixtures في صفحات الأراضي الجديدة.

## 3. التصميم الحركي: ما نفذناه وما لم ننفذه

**المنفذ:** `public/orbit-lab.html` مشهد توضيحي قائم بذاته، لا يعتمد على npm أو WebGL إضافي. يستخدم حدود Natural Earth المرخصة مجانًا ومادة لونية مُنشأة محليًا لرسم الكرة، وتتحرك كرة الأرض بصورة مستقلة عن نموذج قمر صناعي مبسط. يحتوي على تحريك `requestAnimationFrame` بمعدل مستهدف ~30fps، حد أعلى لدقة تكوين الكرة لتقليل عبء CPU، واحترام `prefers-reduced-motion`، وخيار في الصفحة الرئيسية للتبديل بين الصورة الأصلية والمشهد المتحرك. التوثيق يعلن صراحة أن سرعة الدوران مُسرَّعة وأنها ليست محاكاة مدارية فيزيائية أو بيانات NASA حية.

**غير المنفذ:** نموذج GLTF/GLB لقمر حقيقي، خامات PBR للمعدن والألواح الشمسية، ظلال أرضية volumetric، رندر Three.js كامل، satellite ephemeris حقيقي، اختبار معدل الإطارات والبُنى على iOS وAndroid. **لا ينبغي ترويج النموذج الأولي كبديل مكافئ بصريًا للصورة السينمائية الحالية** قبل المقارنة البصرية.

### الخيار الأفضل للإصدار السينمائي النهائي

1. أصلان منفصلان ومشروع حقوق واضح: نسيج أرضي عالي الجودة مرخص (مثال NASA Blue Marble وفق شروط المصدر) + نموذج spacecraft GLB مستقل بحقوق واضحة. لا يُستخرج satellite من JPEG الحالي مع حواف مصطنعة إلا كحل مؤقت.
2. Canvas/WebGL واحد فقط للـHero مشروط بإمكانية الجهاز وبـIntersectionObserver، مع `requestAnimationFrame` موقوف عند الخروج من العرض أو إخفاء التبويب، وDPR محدود. لا تربط كاميرا MapLibre القائمة في `/explore` بمشهد Hero بلا مراجعة استهلاك WebGL/GPU.
3. الكوكب يدور مستقلاً حول محوره، والقمر يسير على مدار مائل مع **حجب صحيح** خلف الأرض وأمامها، وتوجيه panel والـlight direction. حركة المشهد الأولي مرئية، لكن يجب كتابة `Illustrative / not live telemetry` ما لم توجد TLE/ephemerides موثقة.
4. انتقال تصميمي عند الضغط على Explore Earth: cinematic Hero -> current live MapLibre globe -> field. تجنّب crossfade الثقيلة والـCLS والتشغيل التلقائي الطويل على الهواتف.
5. بوابات قبول مستهدفة، **غير مقاسة بعد**: فيديو فحص لمدة 60 ثانية على desktop/mobile، p95 frame time، WebGL context count، dropped frames وCPU throttling، LCP وCLS وINP، reduced motion، Offscreen Pause، Android Chrome وSafari الحقيقي.

## 4. أدلة الاختبار وقيود المراجعة

**التحقق الحقيقي في هذه الجولة:**
- تم فك حزمة ZIP داخل مسار محمي من الخروج، وجرد الملفات والأحجام والتراخيص والأدلة السابقة.
- مدقق `node scripts/verify-manifest.mjs` على النسخة الأصلية نجح **136/136** قبل التعديل.
- جرى تشغيل `node --check` على JavaScript نموذج المدار ومدقق SHA، وتحليل نحوي/تحويل أولي لكل ملفات TS/TSX (42 ملفًا عند آخر فحص، 0 أخطاء syntax). **هذا لا يعادل `tsc --noEmit` أو Next build.**
- جرى إعداد `node scripts/review-regression.mjs` لاختبار سلامة المحتوى ورفض التلاعب والروابط الرمزية وParse كود المدار من دون npm. نُفذت **11/11** حالة فحص من دون npm بعد إعادة تجزئة الحزمة، بما فيها المسار الرمزي للمجلد الوسيط. ونجح `verify-manifest` في **140/140** سجلًا (قبل إعداد سجل الإصدار النهائي).
- أضيفت اختبارات Playwright جديدة لتبديل المشهد المتحرك ولرابط Provenance على 390px، لكنها **مكتوبة وغير منفّذة** في هذه البيئة بسبب التبعيات والمتصفح.

**لم يُتحقق منه بعد هذه التعديلات:** `npm ci`, `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`, `npm run test:e2e`, صور فعلية من المشهد المتحرك، اختبارات 403/429/503 وشبكات 3G المتباطئة، accessibility axe/screen reader، iOS Safari، كلفة الطاقة/الحرارة.
