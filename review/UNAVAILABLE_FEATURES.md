# ASTRAGRON Smart Fields & Globe Coverage — Unavailable & Offline-Scoped Features Disclosure

**Release Branch:** `feat/smart-fields-coverage`  
**Verified Baseline Commit:** `6d9285e` (`feat/farmer-first-ux`)

ASTRAGRON strictly separates verified local capabilities from capabilities requiring operator-supplied external services. None of the offline handlers fabricate place matches, AI parcel boundaries, live crop optimization models, or assistant responses.

| Feature / Capability | Default Behavior Without External Service Keys | Honest Status / Disclosure Exposed to User & API | Fail-Closed Guards |
|---|---|---|---|
| **Live Global Address / Village Geocoder (`GET /api/geocode`)** | `ASTRAGRON_GEOCODER_ENDPOINT` & `ASTRAGRON_GEOCODER_ALLOWED_HOSTS` are unset by default in the standalone bundle. | `GET /api/capabilities` reports `geocoding: { enabled: false, mode: "LOCAL_GAZETTEER_ONLY" }`. Search falls back cleanly to the offline 16-site reference gazetteer plus instant decimal/DMS coordinate parsing and browser GPS pin. | Returns `GEOCODER_NOT_CONFIGURED`; `PUBLIC_OSM_NOMINATIM_BLOCKED` blocks public OpenStreetMap Nominatim autocomplete (`ssrf-guard.ts`). |
| **Satellite AI Field Boundary Suggestion (`GET /api/field-boundaries/suggest`)** | `ASTRAGRON_FTW_SUGGEST_ENDPOINT` & `ASTRAGRON_FTW_ALLOWED_HOSTS` are unset by default. | Returns `200 OK` with `status: "UNAVAILABLE"`, `providerConfigured: false`, and empty `suggestions: []`. Wizard informs farmer honestly and guides them to tap corners manually, draw quick rectangle, trace by GPS, or upload GeoJSON/KML/GPX. | Never synthesizes fake AI parcels; rejects clipped `tileBbox` fragments (`rejectedFragmentsCount`). |
| **Live Custom-Farm Crop & Water Optimization (`liveFarmAnalysis`)** | `ASTRAGRON_BACKEND_URL` is unset (and verified asynchronously via `/health` if configured). | Custom and modified farms check M4 EO source coverage & verified localized exclusion footprints (`POST /api/capabilities/site-check`), save boundaries freely (`allowsFarmSave: true`), and generate honest Coverage/Evidence PDF snapshots without agronomic advice. | `BACKEND_NOT_CONNECTED`, `BACKEND_UNREACHABLE`, `ANALYSIS_NOT_RUN_FOR_INPUT_REVISION`, `MODEL_UNQUALIFIED`. |
| **Global Backend Capability Feed (`GET /api/capabilities/footprints`)** | `ASTRAGRON_CAPABILITY_FOOTPRINTS_ENDPOINT` is unset. | Globe displays only strictly verified localized M4/M14 benchmark & cryosphere exclusions (`LOCAL_SCIENTIFIC_REGISTRY`). All other unassessed croplands worldwide remain neutral (`UNKNOWN_UNASSESSED`). | Never colors unassessed world croplands or M14 `RESEARCH_ONLY` domains in blanket red. |
| **Ask ASTRAGRON AI Assistant (`POST /api/reports/[reportId]/chat`)** | `ASTRAGRON_CHAT_ENDPOINT` is unset. | Composer input is visibly locked (`reportGroundedChat.enabled: false`); API returns `503 CHAT_NOT_CONNECTED` (`answer: null`). Deterministic, zero-hallucination **Non-AI Report Guide** chips read strictly from the current `ReportEnvelope`. | `503 CHAT_NOT_CONNECTED`, `409 REPORT_CONTEXT_MISMATCH`. |
| **Multi-Device Cloud Account Sync (`cloudFarmStorage`)** | `ASTRAGRON_CLOUD_STORAGE_URL` is unset. | Farms, drawn field geometries, and PDF report snapshots persist locally in the browser (`Saved on this device`), with explicit write-error alerts and checksum-verified JSON Backup Export/Import. | `LOCAL_DEVICE_ONLY`, `checksum` tamper check on JSON backup restore. |
| **Universal 5-Year Crop Prescription (`recordedM14`)** | Bundled SHA-256 verified Uppsala M14 archive (`uppsala-demo`). | Read-only research benchmark explicitly abstains (`ABSTAINED`: `0 of 12` comparable policies meet the `100 mm` universal deficit threshold across all 9 weather/water scenarios). | `NO_UNIQUE_WINNER`, `SOURCE_NOT_PROVIDED` on tamper. |
